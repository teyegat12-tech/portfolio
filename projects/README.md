# Каталог проектов Студии 12

Рабочая страница: https://nkorotkevich.com/projects/

Источник дизайна: Figma, файл `6ktBxG7hRTrYnNf1e7BvDV`, фрейм `948:2`, 1920 × 7360. Геометрия исходного макета сохранена в `design-spec.json`. Это справочник, страница не загружает его при работе.

## Как добавлять проекты

Все записи находятся в `projects.json`. Найди нужный раздел и добавь объект в его массив `projects`. Сетка, высота страницы, правые надписи и продолжение левого декора пересчитаются автоматически.

```json
{
  "id": "17",
  "status": "ОПУБЛИКОВАНО",
  "title": "Название проекта",
  "description": "Короткое описание проекта.\nВторая строка при необходимости.",
  "action": "ОТКРЫТЬ ПРОЕКТ ↗",
  "featured": false,
  "links": [
    {"label": "Открыть сайт", "url": "https://example.com/"}
  ]
}
```

`id` должен быть уникальным. Для неопубликованного проекта оставь `links: []` и `action: "В РАЗРАБОТКЕ"`. Наличие записи не означает, что проект уже опубликован: статус обновляем после проверки адреса.

Материалы на диске задаются через `{"label":"Материалы", "local":"Проекты/Название"}`. `local` — путь относительно папки Студии 12. Пользователь один раз задаёт папку в браузере; она хранится только в localStorage. Содержимое локальных материалов, ключи и инструкции не загружаются на сайт.

Перед публикацией запусти `node validate.mjs`. После сохранения изменений в `main` репозитория `teyegat12-tech/portfolio` Vercel автоматически обновляет сайт. Файлы каталога находятся в папке `projects/`. Главная страница портфолио — отдельная, её не заменяем.

## Локальный просмотр

Из папки репозитория: `python3 -m http.server 4173`, затем открой `http://localhost:4173/projects/`. Страница использует JSON, поэтому открывать её двойным щелчком как `file://` не нужно.

## Файлы и дизайн

- `index.html` — структура страницы и окно материалов.
- `style.css` — сетка, типографика, адаптация до 760 px.
- `app.js` — вывод каталога, коллаж, ссылки и локальные пути.
- `projects.json` — единственный список проектов.
- `assets/` — оригинальные элементы Figma, шрифты и фон. Растры сохранены в lossless WebP, повторяющиеся файлы удалены.

Десктоп: левое поле 200 px, две колонки по 680 px, промежуток 64 px; интервалы раздела 60 px; заголовки 78 px; карточки 36 px, первые две 48 px. Шрифты Unbounded и JetBrains Mono, Menlo для части авторских подписей. Акцент #ECFF29. На телефоне одна колонка и отдельные размеры текста.

Не заменять живой текст изображениями. Не дублировать фон плиткой. Не публиковать локальные документы или секреты вместе с каталогом.

Уточнения после просмотра: фон и контурные волны находятся под контентом; левая декоративная полоса и правая микротипографика — над ним. Подпись под AI проекты отнесена на 28 px ниже исходного макета (на мобильном +20 px).
